CONCLUSIONES DEL PROYECTO

Este documento recoge las conclusiones del equipo sobre el proyecto "Generación y clasificación de datos", desarrollado en Java 8 con Eclipse para la materia Conceptos Fundamentales de Programación. El proyecto consistió en generar archivos planos de prueba (productos, vendedores y ventas) y procesarlos para producir dos reportes ordenados de mayor a menor: el dinero recaudado por vendedor y la cantidad vendida por producto.

1. Lo aprendido durante el desarrollo del proyecto

Durante el desarrollo del proyecto se fortalecieron los conocimientos fundamentales de programación en Java, especialmente el uso de variables, tipos de datos, cadenas de texto, estructuras condicionales, ciclos y métodos. También aprendimos a dividir un problema general en tareas más pequeñas, asignando a cada método una función específica. Aprendimos a generar información pseudoaleatoria de productos, vendedores y ventas, a almacenarla en archivos planos y luego a leerla, dividir sus líneas, convertir cadenas en valores numéricos y relacionar la información mediante los identificadores de vendedores y productos. Practicamos el uso de acumuladores para calcular el dinero recaudado por cada vendedor y la cantidad total vendida de cada producto, y aplicamos un ordenamiento de mayor a menor para generar los reportes solicitados.

Además, el proyecto permitió reforzar la creación de clases, métodos auxiliares y variables, y afianzar los principios de la programación orientada a objetos, por ejemplo al representar vendedores y productos como objetos que guardan sus propios datos. Otro aprendizaje fue la evolución de la solución: partimos de datos fijos y arreglos de tamaño limitado, y avanzamos hacia datos generados dinámicamente y listas dinámicas (ArrayList) que permiten procesar cualquier volumen de información. Para algunos integrantes del equipo también fue una oportunidad de aprender o reforzar el manejo de Eclipse y la integración de Git y GitHub con este entorno de desarrollo. Finalmente, comprendimos la importancia de documentar el código, usar nombres claros y manejar posibles errores durante la lectura y escritura de archivos.

2. Posibles aplicaciones en la vida profesional

Los conocimientos adquiridos se pueden utilizar en el entorno profesional para automatizar actividades que normalmente se realizan de forma manual. Por ejemplo, se pueden desarrollar programas sencillos para organizar información de ventas, inventarios, costos, órdenes de trabajo o resultados de inspecciones. El procesamiento de archivos permite consolidar información proveniente de diferentes áreas, calcular indicadores y generar reportes que faciliten el análisis y la toma de decisiones. Una lógica similar a la de este proyecto serviría para clasificar elementos por cantidad, ordenar recursos por consumo o calcular costos por área o responsable.

También reconocimos la importancia de estructurar bien los datos y mantener relaciones coherentes entre distintas fuentes de información. Pasar de datos fijos a datos dinámicos, organizados en clases y listas, hace que una solución sea más reutilizable y fácil de ampliar. En una aplicación profesional, esto equivale a relacionar correctamente, por ejemplo, un vendedor, sus ventas y los productos asociados. Por tanto, las habilidades practicadas son una base para desarrollar soluciones de automatización y análisis de datos más completas.

3. Dificultades presentadas durante el desarrollo del proyecto

Una de las principales dificultades fue conservar la coherencia entre los archivos generados: los vendedores incluidos en los archivos de ventas debían existir en el archivo general de vendedores, y los productos vendidos debían estar registrados en el archivo de productos. Otra dificultad fue procesar correctamente las líneas separadas por punto y coma, convertir precios, documentos y cantidades de texto a valores numéricos, y descartar las líneas con datos inválidos para que no afectaran los totales.

También fue un reto comprender cómo maneja Java los archivos, en particular su creación y lectura en la raíz del proyecto, la actualización de las carpetas en Eclipse y el manejo de excepciones cuando un archivo no existía o contenía información incorrecta. Hubo que entender la diferencia entre generar los archivos de entrada y procesarlos, por lo que se definió un orden de ejecución: primero la clase GenerateInfoFiles y después la clase main. Por último, trabajar con Git desde Eclipse fue distinto a otros entornos, y ponernos de acuerdo como equipo para trabajar de forma coordinada también requirió esfuerzo.
